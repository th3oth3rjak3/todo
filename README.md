# todo

*A programming language. Eventually.*

Welcome to **todo**, yet another attempt at creating a programming language.

The name is both a project name and a statement of intent. Whether this language will ever be finished remains an open question.

## What is this?

todo is an experimental programming language written in Zig.

Its goals are relatively straightforward:

- Be pleasant to write.
- Have simple, readable syntax.
- Avoid unnecessary complexity and ceremony.
- Make common programming tasks feel natural.
- Provide a standard library that doesn't make you question your life choices.

## Project status

<escape>🚧</escape> Under construction. Probably for a while.

The current plan is to start with a tree-walk interpreter and gradually develop the language into something useful.

There are no promises about timelines, feature completeness, or the eventual existence of a package manager.

## Development philosophy

1. Build something that works before worrying about making it perfect.
2. Don't solve problems that don't exist yet.
3. Keep the language simple. We have enough complicated languages already.
4. If a feature takes three months to implement, reconsider the feature.
5. Document decisions before forgetting why they were made.
6. Actually finish something this time. Maybe.

## Technical details

- **Implementation language:** Zig
- **Implementation strategy:** Interpreter first
- **Source file extension:** `.todo`
- **Primary inspiration:** *Crafting Interpreters* by Robert Nystrom

## Final disclaimer

This project may be abandoned, rewritten, redesigned, renamed, or replaced by another programming language project at any point.

In the unlikely event that it reaches version 1.0, please act surprised.
